# מרכז השליטה — דף טריגרים מקומי

דף מקומי שממנו מריצים סקריפטים ואוטומציות **בלחיצה**, בלי לפתוח טרמינל ובלי
לזכור פקודות. הפלט זורם לדפדפן בזמן אמת.

- **אפס תלויות.** ספרייה סטנדרטית של Python בלבד. אין `pip install`, אין `npm`.
- **אפס קוד להוספת אוטומציה.** כל אוטומציה היא אובייקט אחד בקובץ JSON.
- **מאזין על `127.0.0.1` בלבד.** לא נגיש מהרשת.

---

## התחלה מהירה

1. Python 3.9+ מותקן.
2. להוריד את התיקייה ולהריץ:

   ```bash
   python server.py
   ```

   ב-Windows אפשר גם לחיצה כפולה על `start.bat`.
3. הדפדפן נפתח לבד על `http://127.0.0.1:8765`. יופיע **כרטיס דוגמה** שרץ ולא
   עושה כלום — רק כדי שתראו איך הרצה נראית.
4. להעתיק את `automations.example.json` ל-**`automations.json`**, ולערוך.
   מרגע שהקובץ הזה קיים, הוא זה שנטען.

⚠️ **חלון השרת חייב להישאר פתוח** כל עוד אוטומציה רצה. סגירה שלו הורגת את ההרצה.

---

## איך מוסיפים אוטומציה

עורכים רק את `automations.json`. הקוד לא מכיר אף אוטומציה, והדפדפן בונה את
הכרטיס לבד מההגדרה — אין מה לגעת לא ב-Python ולא ב-HTML.

```json
{
  "id": "daily-report",
  "icon": "📊",
  "title": "דוח יומי",
  "subtitle": "מה זה עושה, בשורה אחת",
  "duration": "~2 דקות",
  "cost": "$0.40",
  "cost_confirm": true,
  "cwd": "{HOME}/projects/reports",
  "command": ["{PYTHON}", "run.py", "--date", "{date}"],
  "fields": [
    {"name": "date", "label": "תאריך", "type": "date", "required": true}
  ]
}
```

**קיצורי נתיב** (ב-`cwd`, ב-`command` וב-`logo`):

| קיצור | מה זה |
|---|---|
| `{HOME}` | תיקיית הבית של המשתמש |
| `{REPO_ROOT}` | שתי רמות מעל התיקייה הזו |
| `{HERE}` | התיקייה של `server.py` |
| `{PYTHON}` | ה-Python שמריץ את השרת |

**סוגי שדות:**

| סוג | מה מקבלים |
|---|---|
| `text` | שדה טקסט |
| `number` | מספר, עם `min` אופציונלי |
| `date` | יומן תאריכים. שולח `YYYY-MM-DD` |
| `audiofile` | בורר קבצי מדיה שסורק את התיקיות שב-`file_search_dirs` |

שתי אפשרויות לשדה `date`: `"default_today": false` פותח אותו ריק במקום על היום,
ו-`"format": "dotted"` ממיר ל-`DD.MM.YYYY` לפני ההרצה.

**איך נבנית הפקודה:** כל `"{שם_שדה}"` ב-`command` מוחלף בערך מהטופס. שדה
לא-חובה שנשאר ריק מפיל את עצמו **ואת הדגל שלפניו** — כך `--date {date}` נעלם
לגמרי כשלא נבחר תאריך.

**מראה הדף** — כותרת, תת-כותרת, לוגו, פורט ותיקיות חיפוש — הכל ב-`settings`
באותו קובץ. אחרי עריכה צריך להפעיל מחדש את השרת.

## החלטות עיצוב — ולמה

| החלטה | הסיבה |
|---|---|
| **כרטיסים עם שדות, לא כפתורים** | סקריפט אמיתי מקבל ארגומנטים. כפתור בלבד לא היה עובד |
| **המחיר על הכפתור עצמו** | כשלחיצה עולה כסף, המחיר חייב להיות גלוי ברגע ההחלטה |
| **אישור מראש רק ליקר** | חיכוך במקום שבו הוא שווה כסף. על פעולה זולה חיכוך הוא מטרד |
| **פלט זורם בזמן אמת** | עשר דקות בלי סימן חיים = דף שנראה תקוע = סגירה באמצע |
| **שגיאה מוצגת כטקסט גולמי** | אף פעם לא "משהו השתבש". השגיאה המקורית של הסקריפט |
| **כפתור עצירה** | טעות בשדה אחרי 30 שניות לא צריכה לעלות את מלוא המחיר |
| **בורר קבצים בצד השרת** | הדפדפן לא חושף נתיב מלא של קובץ. השרת סורק ומגיש רשימה |
| **ערכי טפסים נשמרים** | `localStorage`. נתיב קובץ לא נשמר — הוא משתנה בכל הרצה |

## אבטחה

| | |
|---|---|
| מאזין על | `127.0.0.1` בלבד |
| הרצת פקודות | `subprocess` עם רשימת ארגומנטים ו-`shell=False`. אין הזרקת פקודות, ונתיבים עם רווחים ועברית עוברים בלי בעיות ציטוט |
| סודות | **לא שמים מפתחות ב-`automations.json`.** הסקריפט שלכם טוען את הסודות שלו בעצמו (למשל מ-`.env` שמוחרג מ-git) |
| אימות | אין. הדף מיועד למשתמש יחיד על המחשב שלו |

## פתרון בעיות

| תסמין | סיבה | פתרון |
|---|---|---|
| `Cannot listen on 127.0.0.1:8765` | השרת כבר רץ בחלון אחר | להשתמש בחלון הפתוח, או לסגור אותו ולהריץ שוב |
| "אין קשר עם השרת" | חלון השרת נסגר | להריץ שוב |
| `Config error: ...` | JSON לא תקין | לבדוק פסיקים וגרשיים ב-`automations.json` |
| הקובץ לא מופיע בבורר | הוא לא באחת מתיקיות החיפוש | לבחור "✎ נתיב אחר…" ולהדביק נתיב מלא |
| `ModuleNotFoundError` בהרצה | הסקריפט רץ עם Python אחר מזה שבו מותקנות הספריות | להצביע ב-`command` על ה-Python של הסביבה הווירטואלית של הפרויקט |

השגיאה שמוצגת בדף היא תמיד ההודעה **המקורית** של הסקריפט. את הפתרון מצליבים
מול התיעוד של אותו סקריפט.
